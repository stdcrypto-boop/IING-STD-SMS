# IING STD SMS
Lightweight, ad-free Android SMS app (early development).

## Status
Initial source code and GitHub Actions debug build. **Not ready to replace your primary SMS app.**

## Planned before release
- Proper default SMS app incoming-message persistence and notifications
- Reliable send status and multi-SIM selection
- Contact names, search, delete conversations, and modern Material 3 design
- Real-device SMS send/receive testing

## Build
GitHub Actions > Build Android APK > Artifacts. The debug APK is unsigned for release but debug-signed for testing.
